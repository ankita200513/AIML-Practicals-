# AIML Practicals

This repository contains 10 Artificial Intelligence and Machine Learning practicals implemented using Python.

## Practicals Included
1. Correlation and Variable Association
2. K-Means Clustering
3. Principal Component Analysis (PCA)
4. Naive Bayes Classification
5. K-Nearest Neighbors (KNN)
6. Linear Regression
7. Support Vector Regression (SVR)
8. Ridge and Lasso Regularization
9. CCTV Object Detection
10. Multimodal Fake-News Detection

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib
- OpenCV

## Features
- Implementation of machine learning algorithms
- Dataset analysis and preprocessing
- Model training and evaluation
- Performance metrics and visualizations
- Practical examples of AI/ML applications

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run a practical from its respective folder:

```bash
python practical.py
```

## Objective

To understand and implement fundamental AI/ML algorithms and explore their applications in data analysis, classification, regression, clustering, and computer vision.

## Note
These practicals are intended for educational purposes. Results depend on the datasets and experimental setup used.
